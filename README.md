# CampusConnect

CampusConnect is an open-source campus event management application designed to help university students discover and participate in academic, technical, social, and innovation events.

The project demonstrates modern open-source software development using React and Express.js.

## Features

- View upcoming campus events
- View event dates and locations
- View event descriptions
- Register attendance for an event
- Display the number of students attending
- REST API for event management
- Automated API testing
- Responsive web interface
